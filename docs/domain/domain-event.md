# ドメインイベント

## 更新対象

- ドメインイベントの追加、削除、名称、発行元、発生条件、用途を変更した場合に更新する。

## 命名ルール

- `Event` はユーザーの予定を表す。
- ドメインイベントの基底名は `DomainEvent` とする。
- ドメインイベント名は業務上の過去形にする。

## ドメインイベント一覧

### user

| イベント | 発生条件 | 用途 |
|---|---|
| `UserRegistered` | ユーザー登録が完了した | ユーザー登録後の後続処理 |
| `CalendarSelectionChanged` | 同期対象カレンダーの選択が変化した | 同期対象カレンダーの変更通知 |
| `CalendarInitialSyncRequested` | 同期対象カレンダーを新たに選択した | 選択追加後の初回同期要求 |

### event

| イベント | 発生条件 | 用途 |
|---|---|
| `EventScheduled` | Google Calendarから投影する予定を新規作成した | 予定追加後の下流処理開始 |
| `EventRescheduled` | 予定時刻、タイトル、概要、場所のいずれかが変化した | 予定変更後の目的地・混雑再評価 |
| `EventNotificationTimingChanged` | 予定時刻またはリマインド間隔が変化した | 通知時刻に影響する変更後の通知再計算 |
| `EventCancelled` | Google側で予定がキャンセルされた、投影対象期間外になった、またはフル同期結果から消えた | 予定削除後の通知キャンセル |
